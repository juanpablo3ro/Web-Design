# Cuestionario de Salud PRODI v1.1

Sistema de captura de historias clínicas desarrollado con **Flask** y **SQLite3**.

## Características
- Cuestionario médico completo (42+ variables).
- Cálculos automáticos de IMC, riesgo de apnea y salud mental vía JavaScript.
- Base de datos relacional para almacenamiento seguro.

## Cómo ejecutar
1. Activar ambiente virtual: `source .venv/bin/activate`
2. Instalar dependencias: `pip install flask`
3. Ejecutar: `python app.py`
4. Acceder a: `http://127.0.0.1:5001`
